A small, warm fortune for a freshly liquidated crypto trader, wishing their next margin call a less expensive origin.

## How it works

Run with Python 3.13; only the standard library is used:

```sh
python3 main.py
```

The program writes exactly 41 UTF-8 characters and 9 words to `entry.txt` in `MAKEFUN_OUTPUT_DIR`, with no trailing newline. When the variable is unset, it uses `out`, falling back to a temporary directory if that default cannot be created or accessed for writing. It re-reads and validates the output, then prints its SHA-256 digest.
